📖 Project Overview

This repository contains a static frontend implementation of a fashion e-commerce storefront inspired by Myntra.

The goal of this project is to:

Practice frontend development

Understand e-commerce UI structure

Learn responsive web design

Improve JavaScript logic for filtering and sorting

No backend or database is used.

✨ Features

📱 Fully Responsive Layout (Mobile-First)

🛍️ Product Grid with:

Product Image

Title

Price

Rating

🔎 Search Functionality

🎯 Category Filtering

↕️ Sorting (Price Low → High / High → Low)

🪟 Optional Product Quick View Modal

♿ Semantic and accessible HTML structure

🛠️ Tech Stack

HTML5

CSS3 (Flexbox & Grid)

JavaScript (ES6)

No frameworks or libraries are used.

🎯 Learning Objectives

After completing this project, you will understand:

How to structure a real-world frontend project

How product cards are dynamically rendered

How filtering and sorting logic works in JavaScript

How responsive design works using media queries

How to organize files and folders properly

This project is ideal for:

Beginners learning frontend

Students building portfolio projects

Practice before learning React / Angular / Vue
