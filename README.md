## Getting Started

### Prerequisites

A modern web browser. For local development you can use a simple static server. Examples:

- Python 3: `python -m http.server 8000`
- Node (http-server): `npx http-server -c-1`

### Install & Run Locally

1. Clone the repository

```bash
git clone https://github.com/NavajShaikh03/myntra.git
cd myntra
```

2. Serve the site (example using Python 3)

```bash
python -m http.server 8000
```

3. Open your browser at `http://localhost:8000` and navigate to `index.html` (or the app entry file).
